结论

规则写在 index.css 既有的 @layer base 与 @layer components 中，每个页面继承；Tailwind utilities 仍能在单个元素上覆盖。

中文标题用 CjkText 调 BudouX，只在词间插入 <wbr>；.app-cjk-breaks 再应用 word-break: keep-all + overflow-wrap: anywhere。短标题若只有一个词，原样返回，不产生额外 DOM，也不会在没有断点时使用 keep-all。

截断统一走 TruncatedText：只有 scrollWidth > clientWidth 时才出现完整文本 Tooltip；flex 行内的触发器用 flex-1 min-w-0，不再让文字把行撑开。

数字在会变化或成列的位置使用 tabular-nums。本机 SF Pro / system-ui 确认带有 tnum 特性：比例数字下 111111 为 38.06px、000000 为 52.02px；开启 tabular 后两者都是 52.02px。

01 / HEADING

标题按词断行，并平衡两行长度

390px 宽、150% 字号下的真实卡片标题。默认字号时这条标题不会换行，所以放大到 24px 根字号让换行发生。修复前在词内断开；修复后在 BudouX 词界断开，并由 text-wrap: balance 平衡两行。

text-wrap: balance keep-all wbr 词界
02 / PARAGRAPH

段末不再只剩一个「员」

战斗页的高级设置说明，390px 宽、三行。修复前 Chrome 把「员。」单独留在末行；text-wrap: pretty 重新分配后，末行变成「干员。」。这只是段落换行，不改字号、行高或容器。

text-wrap: pretty 末行 1 → 3 字符
03 / NUMBER

变化的数字不再改变宽度

同一个仪表数值，分别填入 18% 与 80%，强制数字宽度差出现。修复前 1 比 8 窄，整段右对齐数字的左边缘会跳；开启 tabular-nums 后两个值宽度一致。

04 / TRUNCATION

真的被截断时才出现 Tooltip

控制台「今日掉落」摘要。修复前只有省略号，完整内容无处查看；修复后 TruncatedText 实测 scrollWidth 236 / clientWidth 96，标为 data-truncated="true"，悬停显示完整材料清单。未截断的同类文本不会出现提示。

05 / CJK + LATIN

中文与拉丁、数字之间自动留薄缝

干员名「麒麟R夜刀」与标签「精2」是真实的无空格混排。修复前 R 与 2 紧贴汉字；text-autospace: normal 后在汉字与拉丁/数字之间插入薄缝。名称文本宽度 65.58 → 69.08px，标签 19.25 → 20.75px。

text-autospace: normal +3.50px / +1.50px

断行规则审计

按你的要求，逐条说明 line-break: anywhere 与 word-break: break-all 的去留。

  • 0
    line-break: anywhere：0 处，未删除也未新增。 在 client/src 的 CSS、TS、TSX 中全量搜索无结果。需要兜底断行的位置原本就用 overflow-wrap: anywhere 或 Tailwind break-words，包括配置路径/错误、掉落错误、统计数据错误和日志消息。
  • 1
    word-break: break-all：保留 1 处。 client/src/components/CombatTasks.tsx:1992 的 copilot.uri 是 font-mono 技术 URI，没有中文标点，窄预览里必须允许任意断行；CSS 避头尾规则对它没有意义。配置路径等其余位置继续用 break-words + [overflow-wrap:anywhere]，并有测试断言不使用 break-all。
  • 2
    Canvas / SVG / 手写 JS 换行：不适用。 应用没有 fillText、SVG <text> 或手写字符串截断；只有列表 slice 和仪表 sparkline，不承载正文换行。

限制与说明

  • A
    标题截图用了 150% 字号。 390px 默认字号下，产品现有标题都不会换行；为了看到 balance / keep-all 的差异，把根字号设为 24px。真实响应式状态仍然是逐级继承的。
  • B
    混排示例用真实标签，而不是伪段落。 产品正文已经用显式空格分隔拉丁词（如“由 MaaCore 校验”），text-autospace 不会在已有空格处再加缝。真正无空格的是干员名「麒麟R夜刀」和「精2」标签，因此用它们展示。
  • C
    text-spacing-trim 目前 Chrome only。 其他浏览器忽略该声明；text-autospace 同样按渐进增强处理。
  • D
    没有可测的 table / canvas / SVG 文本。 应用里没有 <table>、fillText 或 SVG <text>；全局规则为未来内容保留，当前没有对应页面改动。
  • E
    仍保留少量低价值截断。 技术 URI、aria-hidden 的拖拽影子、已有原生 title 的状态/名称、短静态标签没有迁移到 TruncatedText，避免给数百个卡片增加包装层；高价值的长文本截断点已迁移。
