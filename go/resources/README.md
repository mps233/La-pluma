# Bundled resources

- `scrcpy-server` is the official `scrcpy-server-v5.0.1` release asset from
  Genymobile/scrcpy (Apache License 2.0). It is pushed to the device at runtime
  and speaks the scrcpy 5.0.1 wire protocol over an adb tunnel.
- `icon.png` is the La Pluma application/tray icon.

The desktop app launches the server directly.
